# Content production packet

Copy and fill this template for each language-specific unit. This is an editorial artifact,
not an API payload. Replace prompts with concrete content; mark unknowns and their impact.

## Identity and source evidence

- Working key/title; version/date; author/reviewer; status: draft / review / ready.
- Learner and use context; instrument(s); language/locale; difficulty.
- Source repository revision and reviewed source paths/sections.
- Existing related content and why this unit is needed.
- Curriculum participation: yes/no. If yes: track/course/path/lesson keys, principles,
  position, assumptions and closing application; alignment deviations for review.
  If no: record standalone explicitly and skip placement fields.

Difficulty: beginner / early_intermediate / intermediate / advanced / expert.
Explain the classification through the actual attempt; list curator gaps instead of inventing keys.

## Learning promise

- By the end, the learner can: one observable action in a musical context.
- Why it matters now: concrete payoff, including the purpose of each exercise element.
- Assumed knowledge: each prerequisite, a quick check, exact reference/section and an
  inline bridge or alternative if needed. State language/access requirements.
- Estimated time and what is deliberately outside this narrow outcome.

## Learner-facing sequence (write fully in the target language)

| Beat | Actual learner-facing copy and asset | Learner action | Value and success/feedback |
|---|---|---|---|
| Hear/see the payoff | Practical musical example | Notice a specific feature | Why this matters |
| Get the method | Complete steps and annotated demonstration | Follow the method | No hidden step |
| Try it | Concrete task with stimulus and response | Listen/select/tap/play | Answer/rubric and rationale |
| Correct and retry | Common error and focused correction | Change one thing and repeat | Observable improvement |
| Apply | Phrase, groove, lick or repertoire fragment | Use the skill in music | Success check |
| Continue | Useful practice instruction and references | Repeat with variation | Today's payoff already delivered |

These are learning beats, not a mandatory six-slide deck. Merge beats when clear.
Feedback may follow an attempt; this is pedagogical timing, not withholding a technique.
