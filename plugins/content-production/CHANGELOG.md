# Changelog

## 1.4.1 — 2026-11-05

- Make editorial walkthroughs and applicable shared validators the default lesson checks.
- Require a concrete software change or recurring error to justify new automated tests.
- Distinguish PowerPoint inspection from native exercise behavior verification.

## 1.4.0 — 2026-11-04

- Trace teaching steps and learner actions to the observable lesson outcome.
- Map likely mistakes to actionable feedback and fresh practice examples.
- Require a learner walkthrough and an editorial inspection of the preview.
- Plan native delivery and fallbacks for essential interactions.
- Record reusable skill improvements with evidence and a check for the next lesson.
- Review exercises in drafts, author them in MotifPath and exclude them from final PowerPoint files.

## 1.3.0 — 2026-11-02

- Capture MOT-160 visual-draft review decisions and the syllabus/transition review gate.
- Require a dedicated application opening per lesson with immediate use and concrete
  connections to future subjects, including at beginner level.
- Clarify diagram naming, recognizable fretboard context, practice labels and precise
  internal/external resource mapping without implying installed content or runtime support.
- Align the skill, production packet and presentation guide; retain the explicit audio gate.

## 1.2.0 — 2026-10-18

- Replace the ten-slide starter with a 47-slide MotifPath presentation library,
  editable music diagrams, six native layouts and a filled pt_BR lesson example.
- Add a PowerPoint template, font/artwork kit and guidance for consistent reuse.
- Require visual review as well as structural validation for content presentations.

## 1.1.0 — 2026-10-18

- Add separately runnable Plan, Do, Check and Act phases with resumable cycle records.
- Distinguish evidence, review, runtime verification and release decisions at phase exits.
- Add editable presentation deck with learner layouts and author-review pages.

## 1.0.0 — 2026-10-18

- Add practical, self-sufficient, localized and classified content-production workflow.
- Add conditional curriculum alignment, modality selection and native-capability gates.
- Add reusable production packet and presentation proposal with Google Slides assessment.
